HTML Overview

HTML stands for Hypertext Markup Language. HTML is the standard language for creating web pages.

HTML describes the structure of a webpage using markup.

<html>...</html>

HTML elements are represented by tags.

  • Paragraph: <p>...</p>
  • Header: <h1>...</h1>
  • Link: <a href="... ">...</a>

CSS Overview

CSS stands for Cascading Style Sheets. CSS describes how HTML elements are to be displayed on screen.

The primary purpose of CSS is to style web pages.

color: blue;

CSS can control the layout of multiple web pages all at once.

  • Selectors: h1 { color: red; }
  • Classes: .classname { ... }
  • IDs: #idname { ... }

JavaScript Overview

JavaScript is a programming language used to make web pages interactive.

It can update and change both HTML and CSS.

console.log("Hello, world!");

JavaScript can also be used to create animations.

  • Variables: let x = 5;
  • Functions: function myFunction() { ... }
  • Events: element.addEventListener('click', function() { ... });

Git Overview

Git is a version control system that lets you manage and keep track of your source code history.

Git allows multiple developers to work on the same project without interfering with each other's work.

git commit -m "commit message"

It also allows you to revert to previous versions of your code.

  • Clone repository: git clone ...
  • Add changes: git add .
  • Push changes: git push origin master

Responsive Design

Responsive web design (RWD) is an approach to web design that makes web pages render well on various devices.

RWD uses fluid grids, flexible images, and media queries.

@media (max-width: 600px) { ... }

It ensures that users have a good experience on any device, whether desktop, tablet, or mobile phone.

  • Media Queries: @media screen and (min-width: 600px) { ... }
  • Fluid Grids: Use percentage instead of fixed units.
  • Flexbox/Grid Layout: For responsive layout management.
